
# 🏥 SmartCare+

SmartCare+ is a modern **Doctor Appointment & Healthcare Management Platform** built with **Next.js, Node.js, and MongoDB**.  
It allows users to find doctors, view details, and book appointments easily.

---

## 🚀 Features

- 👨‍⚕️ Browse top-rated doctors
- 📅 Book doctor appointments
- 🔐 Secure authentication (Email & Google login)
- 🧑‍💼 User dashboard for managing appointments
- 📱 Fully responsive UI (Mobile & Desktop)
- ⚡ Fast performance with Next.js App Router
- 🌐 REST API integration (Node.js + Express)
- 🛡️ Protected routes with JWT authentication

---

## 🛠️ Tech Stack

### Frontend
- Next.js 14+ (App Router)
- React.js
- Tailwind CSS
- React Icons
- React Toastify

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication

---

## 🔐 Authentication Flow
- Email & Password login
- Google OAuth login
- JWT token stored in headers
- Protected routes for secure data access

---

## 🚀 Deployment
🌐 Frontend & Backend → Vercel
🗄️ Database → MongoDB Atlas
